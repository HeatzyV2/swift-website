FAQ

Questions fréquentes

Swift Client est-il gratuit ?

Oui. Le launcher et le client en jeu sont gratuits. Certaines capes et certains pets s'obtiennent avec des pièces, mais tout le reste est accessible à tous.

Il me faut un compte Minecraft ?

Oui, pour jouer en ligne il faut un compte Minecraft Java acheté, connecté via Microsoft. Aucun compte Swift n'est nécessaire : il est créé automatiquement la première fois que tu lances le client.

Est-ce que je peux être banni sur un serveur ?

Swift Client ne contient aucun cheat. Ses modules sont de l'affichage et du confort, comme les autres clients populaires. Vérifie tout de même les règles de chaque serveur.

Windows affiche un avertissement à l'installation.

SmartScreen prévient pour les applications récentes. Clique sur « Informations complémentaires » puis « Exécuter quand même ». L'installeur vient directement de nos releases GitHub.

Quelles versions de Minecraft sont supportées ?

Le launcher lance toutes les versions de Minecraft Java. Le client en jeu Swift fonctionne sur la dernière version (Fabric 26.2).

Qu'est-ce que vous collectez ?

Aucune télémétrie. Le client contacte seulement les services nécessaires : Microsoft et Mojang pour la connexion, Modrinth pour les mods, et notre serveur pour les amis, les cosmétiques et l'hébergement de monde. Tes statistiques (niveau, série, record de lancement) restent sur ton ordinateur.

Je peux désactiver Zip ?

Oui : Paramètres, puis Thème, et coupe « Zip, le compagnon ». Il est aussi masqué quand la fenêtre est étroite.
